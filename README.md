# D.L.P. — Delegacia da Língua

Jogo educativo de RPG para investigar o desaparecimento de Henrique e aprender Língua Portuguesa.

## Recursos

- 5 estações: concordância (Anne), fake news (Bryan), ortografia (Bedin), vocabulário (Gabriel D.) e caso final estilo Enem (Manuella).
- Níveis Cadete, Investigador e Agente Especial.
- Perguntas e alternativas embaralhadas a cada investigação.
- Vidas, pontuação, feedback explicativo e certificado.
- Layout responsivo para celular, tablet e desktop.
- Progresso e perfil com nome/e-mail salvos no `localStorage` do navegador.

## Como executar

Abra `index.html` diretamente no navegador. Não há dependências nem servidor obrigatório.

> O salvamento por e-mail é local neste protótipo: o e-mail identifica o perfil, mas não envia dados para um servidor. Para sincronizar entre dispositivos, será necessário adicionar um backend e autenticação.

## GitHub Pages

Em **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)`. Depois, o jogo ficará disponível no endereço do GitHub Pages do repositório.
